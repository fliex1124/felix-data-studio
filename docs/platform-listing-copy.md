## 通用商品简介

你是否经常重复整理表格、制作固定报表，或需要把网页、汇报和商品展示做得更清楚？

Felix Data Studio 面向小微企业、个体经营者和职场团队，提供 Excel 报表自动化、数据分析与看板、PPT 与商业报告、网页、内部工作台、微信小程序、商品文案及电商视觉设计服务。先确认目标、素材、交付物、周期和修改次数，再报价开工。

## 视觉与内容服务范围

- PPT 与商业报告：基于客户确认的文字和数据，整理内容层级、母版、版式、图表与表格；整份报告代写需单独确认。
- 商品文案与卖点：基于真实产品资料，整理标题、短文案、主图文字和详情页内容大纲。
- 电商与社媒视觉：提供商品主图、详情长图、活动海报、横幅、短视频封面、社交媒体配图及常用尺寸导出。
- 店铺视觉套装：可组合头像、店招、横幅、主图、详情图、活动海报、短视频封面和社交媒体配图。
- 短视频相关交付仅限封面和静态配图，不包含拍摄、剪辑、配音、发布或账号运营。
