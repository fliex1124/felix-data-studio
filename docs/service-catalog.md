# Felix Data Studio 服务目录

## 1. 企业数据整理与分析

适合：需要整理 Excel、CSV、业务台账或经营数据的团队。

交付内容：数据清洗、字段规范、统计分析、可视化图表和结论说明。

客户需提供：原始数据样例、指标口径、希望解决的问题。

## 2. Excel 报表自动化

适合：每周或每月重复制作固定报表的团队。

交付内容：标准模板、计算规则、自动汇总流程、使用说明和维护建议。

客户需提供：历史报表、数据来源、更新频率和最终使用人。

## 3. 数据看板

适合：需要持续查看销售、运营、财务或项目进度的团队。

交付内容：指标设计、看板页面、筛选条件、权限建议和导出能力。

## 4. 企业网页与工作台

适合：需要官网、内部查询页面、表单或轻量管理系统的团队。

交付内容：页面结构、视觉界面、前端开发、基础部署和交付文档。

## 5. 微信小程序原型与开发

适合：需要移动端查询、提交、预约或信息展示的团队。

交付内容：功能原型、页面开发、接口对接建议和测试清单。

## 6. 海报与产品详情图设计

适合：需要电商商品主图、产品详情页长图、活动海报或宣传横幅的商家与团队。

交付内容：信息层级梳理、版式设计、常用尺寸图片、约定范围内的修改及可编辑源文件。

客户需提供：产品原图、品牌素材、准确文案、目标平台尺寸、参考风格及有权使用的字体或图片。客户应确保所提供素材拥有合法使用权限。

## 统一交付流程

需求沟通 → 数据与流程梳理 → 方案确认 → 首版交付 → 使用反馈 → 优化维护
