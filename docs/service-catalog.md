# Felix Data Studio 服务目录

网站提供 8 类标准服务和 1 个组合套餐。以下周期与交付内容仅供初步评估，最终以双方确认的素材数量、页面或页数、修改次数、交付格式和验收标准为准。

## 1. Excel 报表自动化

适合：每周或每月重复制作固定报表，需要合并、核对或计算多份表格的团队。

参考周期：2-5 个工作日。

交付内容：数据结构与字段整理、公式或脚本规则、可重复更新的模板、操作说明和验收样例。

客户需提供：脱敏后的历史报表、数据来源、更新频率、计算口径和最终使用环境。

## 2. 数据分析与看板

适合：需要持续查看销售、运营、财务、人力或项目进度的团队。

参考周期：3-7 个工作日。

交付内容：数据清洗、指标口径、趋势与结构分析、看板页面、筛选条件和导出方案。

客户需提供：脱敏后的数据样例、业务口径、查看维度和期望解决的问题。

## 3. PPT 与商业报告

适合：经营复盘、工作总结、项目方案、路演材料和其他需要统一表达的汇报场景。

参考周期：常规范围 2-5 个工作日，具体按页数和内容成熟度确认。

交付内容：内容层级整理、母版与版式统一、图表和表格优化，以及订单约定的 PPT、PDF 或可编辑源文件。

客户需提供：已确认的文字、数据、品牌规范、目标受众、使用场景和参考风格。默认不包含整份报告代写；如需文案撰写或深度改写，应单独确认范围。

## 4. 企业网页与活动页

适合：需要服务介绍、作品展示、活动报名或轻量信息发布页面的团队。

参考周期：5-10 个工作日。

交付内容：页面结构、响应式界面、基础交互、表单方案、源码及部署与维护说明。

客户需提供：准确的页面文案、品牌素材、功能范围、参考页面和部署条件。

## 5. 内部工作台

适合：需要表单提交、数据查询、客户管理或轻量业务后台的团队。

参考周期：7-15 个工作日。

交付内容：角色与流程梳理、表格和表单界面、查询功能、数据接口与权限建议。

客户需提供：脱敏业务样例、使用角色、操作流程、字段规则和现有系统情况。

## 6. 微信小程序

适合：需要移动端展示、查询、预约或信息提交等轻量业务的团队。

参考周期：10-20 个工作日。

交付内容：功能原型、页面开发、接口对接、测试清单以及订单约定的发布材料。

客户需提供：主体和认证情况、功能范围、内容素材、接口条件与目标发布时间。认证、服务器及其他第三方费用不默认包含在开发报价中。

## 7. 电商与社媒视觉

适合：需要商品主图、产品详情页长图、活动海报、店铺横幅、短视频封面或社交媒体配图的商家与团队。

参考周期：单项通常 2-4 个工作日，多尺寸或成套设计另行确认。

交付内容：信息层级梳理、版式设计、常用尺寸图片、约定范围内的修改及源文件。

客户需提供：准确的产品文案、清晰原图、品牌素材、目标平台尺寸、参考风格，以及有权使用的图片、字体和商标。

短视频相关服务仅包含封面和静态配图，不包含拍摄、剪辑、配音、发布或账号运营。

## 8. 商品文案与卖点梳理

适合：已有真实产品资料，但商品标题、核心卖点或详情页内容层级不够清楚的商家。

参考周期：2-4 个工作日。

交付内容：受众与使用场景梳理、商品标题和短文案、卖点层级、主图文字以及详情页内容大纲。

客户需提供：真实准确的产品参数、功能、资质、价格与促销规则。文案服务不包含虚构销量、评价、资质、对比数据或产品功效，也不承诺平台审核、流量、转化或销售结果。

## 店铺视觉组合套餐

适合：需要集中完成品牌基础素材、商品上新素材和活动推广素材的商家。

可组合内容：头像、店招、横幅、商品主图、详情页长图、活动海报、短视频封面和社交媒体配图。可按需要搭配商品文案与卖点梳理。

套餐中的具体数量、尺寸、修改次数、交付格式和源文件范围会在开工前确认。短视频部分仍仅包含封面和静态配图，不包含拍摄、剪辑、发布或运营。

## 案例展示规则

- 演示方案使用模拟数据或自制素材，并明确标注为“演示”，不代表真实客户业绩。
- 真实项目只有在获得客户授权并完成脱敏后才会进入案例库。
- 未经授权不展示客户名称、联系方式、订单信息、内部数据、品牌标识或可识别素材。
- 效率、流量、转化和销售等结果数据只有在可以核验且获准公开时才会展示，不以推测数据代替真实结果。

## 统一交付流程

需求沟通 → 提供脱敏样例或有权使用的素材 → 确认范围、周期与报价 → 首版交付 → 约定范围内修改 → 验收与交付
