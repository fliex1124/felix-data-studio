# Felix Data Studio

面向小微企业、个体经营者和职场团队的数据分析与效率自动化服务网站，涵盖 Excel 报表自动化、数据看板、网页、工作台和微信小程序开发。

## 在线访问

[https://fliex1124.github.io/felix-data-studio/](https://fliex1124.github.io/felix-data-studio/)

## 网站内容

- 5 类标准服务及参考周期
- 3 个明确标注为模拟数据的演示项目
- 合作流程、交付边界和常见问题
- 不上传数据的本地需求摘要工具
- 独立的隐私与服务边界页面
