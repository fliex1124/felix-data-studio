# Felix Data Studio

面向小微企业、个体经营者和职场团队的数据自动化、数字工具与商业视觉服务网站，涵盖 Excel 报表自动化、数据看板、PPT 与商业报告、商品文案、电商视觉、网页、工作台和微信小程序开发。

## 在线访问

[https://fliex1124.github.io/felix-data-studio/](https://fliex1124.github.io/felix-data-studio/)

## 网站内容

- 8 类标准服务、参考周期及店铺视觉组合套餐
- 闲鱼、淘宝、拼多多和小红书的多平台渠道状态与统一服务编号
- 4 个明确标注为模拟数据的演示项目，以及仅展示授权脱敏项目的真实案例库
- 合作流程、交付边界和常见问题
- 支持来源平台和服务编号的本地需求摘要工具，不上传填写内容
- 独立的隐私与服务边界页面

## 商品与素材

- 11 个首批平台商品方向及唯一商品编号
- 11 套可重新生成的 HTML 主图模板
- 11 张适合平台上传的最终主图
- 统一的展示价说明、服务映射、素材要求和发布状态
